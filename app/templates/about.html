About AI Assistant

This AI Assistant is a full-stack web application designed to answer programming and technology-related questions using a Large Language Model (LLM). The project demonstrates both frontend and backend development skills while integrating AI services through an API. The application allows users to submit questions, receive AI-generated responses, and interact through a clean, responsive web interface. It was developed as a portfolio project to showcase modern web development practices and AI integration.

Project Overview

This project demonstrates:

  • Full-stack web development
  • AI API integration
  • Backend development with Python
  • Responsive web design
  • SQLite Database integration
  • Version control using Git and GitHub
  • Deployment to the cloud
